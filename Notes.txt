Option B — Vercel + Google Cloud TTS (recommended for runtime & quality)

Keep your app on Vercel. Implement a Next.js API route that calls Google Cloud TTS (an HTTP/SDK call) and returns a signed URL to a cached MP3 on GCS (or streams it). No binaries needed on Vercel.
Pros: great quality (Telugu neural voices), predictable latency, no server binaries, easy to scale.
Cons: not 100% free always — though for small vocab apps it’s effectively free with generous free tier.

This is production-grade and plays well across all browsers because the client fetches a standard MP3 over HTTPS.


Google Cloud Text-to-Speech (TTS) + caching on Google Cloud Storage (GCS) gives you high-quality Telugu voices, predictable latency, and an easy caching story so your page never waits for synthesis on every click.

1) Setup on Google Cloud (quick)

Create / pick a GCP project.

Enable the Text-to-Speech API and Cloud Storage API in Cloud Console.

Create a Service Account with role Cloud Text-to-Speech Client (or roles/texttospeech.admin) and Storage Object Admin (or fine-grained just for uploading).

Create & download a JSON key for that service account. Keep it secure.

Create a GCS bucket (e.g., mywayapps-tts-cache) in a region near users. Decide: public or private. I recommend private + signed URLs (safer).

Set these env vars for your Next.js server (in Vercel: Environment Variables; locally: .env.local):

GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json   # local dev only if using key file
GCP_PROJECT=your-gcp-project-id
GCS_BUCKET=mywayapps-tts-cache
SIGNED_URL_EXPIRES=3600   # in seconds (1 hour)


On Vercel or other hosts, instead of a file path use the service account JSON as a secret and write it to a temp file at runtime, or set GOOGLE_APPLICATION_CREDENTIALS_JSON and write file in start script. I can show that if you deploy to Vercel.

3) Next.js API route: pages/api/tts.ts

Drop this into your Next.js project. It:

computes a stable cache key (SHA256 of lang|voice|rate|text)

checks GCS for the object

if exists → returns a signed URL to the MP3 (fast)

if miss → calls Google Cloud TTS to produce MP3, uploads to GCS, then returns signed URL.

// pages/api/tts.ts
import type { NextApiRequest, NextApiResponse } from 'next'
import TextToSpeech from '@google-cloud/text-to-speech'
import { Storage } from '@google-cloud/storage'
import { createHash } from 'crypto'

const projectId = process.env.GCP_PROJECT
const bucketName = process.env.GCS_BUCKET
const signedUrlExpires = parseInt(process.env.SIGNED_URL_EXPIRES || '3600', 10)

const ttsClient = new TextToSpeech.TextToSpeechClient()
const storage = new Storage()

function cacheKey(text: string, lang = 'te-IN', voice = 'te-IN-Wavenet-A', rate = 1.0) {
  const h = createHash('sha256')
  h.update([lang, voice, String(rate), text].join('|'))
  return h.digest('hex') + '.mp3'
}

export default async function handler(req: NextApiRequest, res: NextApiResponse) {
  try {
    const text = String(req.query.text || '')
    const lang = String(req.query.lang || 'te-IN')
    const voice = String(req.query.voice || 'te-IN-Wavenet-A') // change voice if preferred
    const rate = Number(req.query.rate || 1.0)

    if (!text.trim()) return res.status(400).json({ error: 'text query parameter required' })

    const key = cacheKey(text, lang, voice, rate)
    const bucket = storage.bucket(bucketName)
    const file = bucket.file(`tts-cache/${key}`)

    // 1) If cached, return signed URL immediately
    const [exists] = await file.exists()
    if (exists) {
      const [url] = await file.getSignedUrl({
        action: 'read',
        expires: Date.now() + signedUrlExpires * 1000,
      })
      return res.status(200).json({ url, cached: true })
    }

    // 2) Not cached — call Google Cloud TTS to synthesize MP3
    const request = {
      input: { text },
      voice: { languageCode: lang, name: voice },
      audioConfig: { audioEncoding: 'MP3', speakingRate: rate },
    }
    const [response] = await ttsClient.synthesizeSpeech(request as any)
    if (!response.audioContent) {
      console.error('TTS returned no audio')
      return res.status(502).json({ error: 'TTS provider returned no audio' })
    }

    // 3) Upload MP3 bytes to GCS
    const buffer = Buffer.from(response.audioContent as Uint8Array)
    await file.save(buffer, {
      contentType: 'audio/mpeg',
      metadata: {
        cacheControl: 'public, max-age=31536000', // long cache on CDN
      },
    })

    // 4) Return signed URL
    const [url] = await file.getSignedUrl({
      action: 'read',
      expires: Date.now() + signedUrlExpires * 1000,
    })

    return res.status(200).json({ url, cached: false })
  } catch (err: any) {
    console.error('TTS API error', err)
    return res.status(500).json({ error: 'internal', detail: err.message || String(err) })
  }
}


Notes:

voice: Google provides many voices; for Telugu use te-IN-Standard-A or Wavenet if available (check Google docs). Replace te-IN-Wavenet-A if not available in your region.

The uploaded files live at tts-cache/<sha>.mp3; you can configure a CDN (Cloud CDN) on top of GCS for global speed.

We set cacheControl long so CDN and browsers cache; signed URL expiry controls access to private bucket.

4) Client code — play reliably in Safari

Use the signed URL returned by the API. This example calls the API then plays the signed URL using a robust helper (keeps audio element in DOM and handles autoplay block).

// client/tts-player.ts
let _currentAudio: HTMLAudioElement | null = null;

async function fetchTtsUrl(text: string) {
  const q = new URLSearchParams({ text, lang: 'te-IN' })
  const resp = await fetch(`/api/tts?${q.toString()}`)
  if (!resp.ok) throw new Error('TTS API failed: ' + resp.status)
  const body = await resp.json()
  return body.url as string
}

export async function playTeluguTTS(text: string) {
  if (!text) return
  const url = await fetchTtsUrl(text)
  await playAudioUrl(url)
}

async function playAudioUrl(url: string) {
  // cleanup previous
  if (_currentAudio) {
    _currentAudio.pause()
    _currentAudio.remove()
    _currentAudio = null
  }

  const audio = document.createElement('audio')
  audio.src = url
  audio.preload = 'auto'
  audio.crossOrigin = 'anonymous'
  audio.style.display = 'none'
  document.body.appendChild(audio)
  _currentAudio = audio

  return new Promise<void>(async (resolve, reject) => {
    audio.onended = () => { cleanup(); resolve(); }
    audio.onerror = (e) => { cleanup(); reject(new Error('audio error')) }

    try {
      await audio.play()
      // success
    } catch (err) {
      // autoplay blocked — create a play button for user gesture
      console.warn('audio.play blocked, showing play button', err)
      const btn = document.createElement('button')
      btn.textContent = 'Play audio'
      btn.style.position = 'fixed'
      btn.style.right = '12px'
      btn.style.bottom = '12px'
      btn.style.zIndex = '9999'
      document.body.appendChild(btn)
      const onClick = async () => {
        btn.removeEventListener('click', onClick)
        if (btn.parentElement) btn.parentElement.removeChild(btn)
        try { await audio.play(); resolve() } catch (e2) { reject(e2) }
      }
      btn.addEventListener('click', onClick)
    }

    function cleanup() {
      try { audio.pause() } catch {}
      audio.src = ''
      if (audio.parentElement) audio.parentElement.removeChild(audio)
      if (_currentAudio === audio) _currentAudio = null
    }
  })
}


Usage:

Put a visible button in your UI that calls playTeluguTTS(word) — ensures the first playback is a user gesture (best UX). After one tap, programmatic plays are usually allowed.
